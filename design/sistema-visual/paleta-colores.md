# Paleta de colores — INEO

## Objetivo
La paleta visual de INEO está orientada a una aplicación clínica: transmite confianza, limpieza, profesionalismo y claridad. Se utiliza una combinación de azul como color principal, cian como apoyo, verde para estados positivos y tonos neutros para superficies y contenido.

## Colores principales

| Token | HEX | Uso |
|---|---|---|
| Primario | `#2563EB` | Navegación activa, botones principales, enlaces y acciones destacadas |
| Secundario | `#0EA5E9` | Elementos informativos, acciones secundarias y gráficos |
| Éxito | `#10B981` | Confirmaciones, estados completados y resultados correctos |
| Índigo | `#4338CA` | Elementos destacados, indicadores y acciones complementarias |

## Colores neutros

| Token | HEX | Uso |
|---|---|---|
| Texto principal | `#111827` | Títulos y contenido de alta prioridad |
| Texto secundario | `#6B7280` | Descripciones, metadatos y ayuda |
| Borde | `#E5E7EB` | Divisores, bordes de tarjetas y formularios |
| Fondo | `#F8FAFC` | Fondo general de la aplicación |
| Superficie | `#FFFFFF` | Tarjetas, formularios, tablas y paneles |

## Colores de estado

| Estado | HEX | Uso |
|---|---|---|
| Éxito | `#10B981` | Operaciones realizadas correctamente |
| Advertencia | `#F59E0B` | Situaciones que requieren atención |
| Error | `#EF4444` | Errores, validaciones y acciones destructivas |
| Información | `#3B82F6` | Avisos y mensajes informativos |

## Reglas de uso
- El azul primario se reserva para acciones principales y navegación activa.
- El verde identifica estados positivos y confirmaciones.
- El rojo se utiliza únicamente para errores o acciones destructivas.
- Los colores deben conservar suficiente contraste para cumplir criterios de accesibilidad WCAG AA.
- Los colores no deben utilizarse como único medio para comunicar un estado; se debe acompañar con texto, iconografía o ambos.
